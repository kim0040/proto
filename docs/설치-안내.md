# 설치 안내

일정 관리 앱을 내 컴퓨터에 설치하는 방법입니다. 자바 같은 다른 프로그램은 따로 설치할 필요가 없습니다.
앱은 **일정 관리** 또는 **ScheduleApp**이라는 이름으로 보이는데, 둘 다 같은 앱입니다.

| 내 컴퓨터 | 가장 쉬운 방법 |
| --- | --- |
| Windows 10/11 | [한 줄로 설치하기](#windows-한-줄로-설치하기) |
| Mac (M1 이후, Apple Silicon) | [한 줄로 설치하기](#mac-한-줄로-설치하기) |

> 내 Mac의 칩 종류는 화면 왼쪽 위 Apple 메뉴 → **이 Mac에 관하여**의 "칩" 항목에서 확인할 수 있습니다.
> "Apple M1", "M2"처럼 M으로 시작하면 됩니다. "Intel"이면 이 앱을 쓸 수 없습니다. [자주 묻는 질문](#자주-묻는-질문)을 참고하세요.

---

## Windows: 한 줄로 설치하기

경고 창 없이 설치부터 바로 가기 만들기까지 한 번에 끝납니다. 관리자 권한도 필요 없습니다.

1. **Windows 키**를 누른 뒤 바로 `powershell`을 입력하고 **Enter**를 누릅니다.
   글자가 한글로 써지면 **한/영** 키를 눌러 영어로 바꿔 주세요. 파란색(또는 검은색) 창이 열립니다.
2. 아래 명령어를 복사해서 열린 창에 붙여 넣고(**Ctrl+V**, 안 되면 창 안에서 **마우스 오른쪽 클릭**) **Enter**를 누릅니다.

   ```powershell
   irm https://raw.githubusercontent.com/kim0040/proto/main/scripts/install-windows.ps1 | iex
   ```

3. 내려받는 동안 1~2분쯤 아무 변화가 없어 보일 수 있습니다. 창을 닫지 말고 기다려 주세요.
4. "설치했어요" 문구가 나오면 앱이 자동으로 열립니다. PowerShell 창은 닫아도 됩니다.

다음부터는 **시작 메뉴**나 **바탕 화면**의 **일정 관리**를 누르면 됩니다.

## Mac: 한 줄로 설치하기

경고 창 없이 응용 프로그램 폴더에 설치한 뒤 바로 엽니다.

1. **⌘(Command) + Space**를 누른 뒤 바로 `터미널`(또는 `Terminal`)을 입력하고 **Enter**를 누릅니다.
2. 아래 명령어를 복사해서 터미널에 붙여 넣고(**⌘ + V**) **Enter**를 누릅니다.

   ```bash
   curl -fsSL https://raw.githubusercontent.com/kim0040/proto/main/scripts/install-mac.sh | bash
   ```

3. 진행 막대가 100%가 될 때까지 기다립니다.
4. "설치했어요" 문구가 나오면 앱이 자동으로 열립니다. 터미널은 닫아도 됩니다.

다음부터는 **⌘ + Space**로 `일정 관리`를 검색하거나, **응용 프로그램** 폴더의 **ScheduleApp**을 누르면 됩니다.

## 직접 내려받아 설치하기

명령어를 쓰기 어렵다면 파일을 직접 내려받아 설치하세요.
이 앱에는 유료 정식 서명이 없어 **처음 한 번만** 경고 창에서 직접 실행을 허용해야 합니다.

| 내 컴퓨터 | 바로 받기 | 설명 |
| --- | --- | --- |
| Windows | [ScheduleApp-windows-x64.msi](https://github.com/kim0040/proto/releases/latest/download/ScheduleApp-windows-x64.msi) | 설치 파일 (추천) |
| Windows | [ScheduleApp-windows-x64.zip](https://github.com/kim0040/proto/releases/latest/download/ScheduleApp-windows-x64.zip) | 설치 없이 풀어서 실행 |
| Mac | [ScheduleApp-macos-arm64.dmg](https://github.com/kim0040/proto/releases/latest/download/ScheduleApp-macos-arm64.dmg) | 설치 파일 (추천) |
| Mac | [ScheduleApp-macos-arm64.zip](https://github.com/kim0040/proto/releases/latest/download/ScheduleApp-macos-arm64.zip) | 풀어서 실행 |

모든 버전과 변경 내용은 [릴리즈 페이지](https://github.com/kim0040/proto/releases)에 있습니다.

### Windows (msi)

1. 내려받은 `ScheduleApp-windows-x64.msi`를 더블클릭합니다.
2. 파란 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보**를 누르고, 아래에 생긴 **실행** 버튼을 누릅니다.
3. **다음**과 **설치**를 차례로 누릅니다.
4. 시작 메뉴나 바탕 화면의 **ScheduleApp**을 눌러 실행합니다.

zip 파일을 내려받았다면 압축을 푼 뒤 `ScheduleApp` 폴더 안의 `ScheduleApp.exe`를 실행하세요.
처음 실행할 때 같은 파란 창이 뜨면 위 2번과 같이 진행하면 됩니다.

### Mac (dmg)

1. 내려받은 `ScheduleApp-macos-arm64.dmg`를 연 뒤, **ScheduleApp**을 옆의 **Applications** 폴더로 끌어다 놓습니다.
2. **응용 프로그램**(Applications) 폴더에서 **ScheduleApp**을 더블클릭합니다.
   "열 수 없습니다" 또는 "확인할 수 없습니다" 창이 뜨면 **완료**(또는 **취소**)를 누릅니다.
3. **시스템 설정 → 개인정보 보호 및 보안**으로 가서, 아래쪽 보안 항목의 **그래도 열기**를 누릅니다.
   Mac 암호를 입력하고, 다시 뜨는 창에서 **열기**를 누릅니다.
4. 다음부터는 그냥 더블클릭하면 됩니다.

> 위 과정이 번거롭다면 [한 줄로 설치하기](#mac-한-줄로-설치하기)를 이용하세요. 경고 창이 뜨지 않습니다.

## 새 버전으로 업데이트하기

처음 설치할 때 쓴 방법을 **그대로 한 번 더** 실행하면 됩니다.
한 줄 설치를 쓰면 켜져 있는 앱을 닫고 새 버전으로 교체한 뒤 다시 엽니다. 기존 일정 데이터는 그대로 남습니다.

## 지우기

앱을 지워도 일정 데이터는 남습니다. 데이터까지 모두 지우려면 아래 [데이터가 있는 곳](#데이터가-있는-곳)의 폴더도 함께 지우세요.

- **Windows (한 줄 설치로 설치했을 때):** 설치할 때처럼 PowerShell을 열고, 아래 두 줄을 한 줄씩 붙여 넣고 각각 **Enter**를 누릅니다.

  ```powershell
  $env:SCHEDULEAPP_UNINSTALL = '1'
  irm https://raw.githubusercontent.com/kim0040/proto/main/scripts/install-windows.ps1 | iex
  ```

- **Windows (msi로 설치했을 때):** **설정 → 앱 → 설치된 앱**에서 **ScheduleApp**을 찾아 **제거**를 누릅니다.
- **Windows (zip을 풀어 썼을 때):** 압축을 푼 `ScheduleApp` 폴더를 지웁니다.
- **Mac:** 응용 프로그램 폴더의 **ScheduleApp**을 휴지통으로 옮깁니다.

## 데이터가 있는 곳

| 컴퓨터 | 폴더 |
| --- | --- |
| Windows | `%APPDATA%\ScheduleApp` (파일 탐색기에서 **Ctrl+L**을 누르고 붙여 넣은 뒤 **Enter**) |
| Mac | `~/Library/Application Support/ScheduleApp` (Finder에서 **⌘ + Shift + G**를 누르고 붙여 넣은 뒤 **Enter**) |

앱의 **설정 → 데이터 폴더 열기**로도 열 수 있습니다.

## 자주 묻는 질문

**PowerShell에 빨간 글씨가 나오고 설치가 안 돼요.**
인터넷 연결을 확인하고 한 번 더 해 보세요. 회사나 학교 컴퓨터는 보안 설정 때문에 막힐 수 있습니다.
그럴 때는 [직접 내려받아 설치하기](#직접-내려받아-설치하기)에서 zip 파일을 내려받아 실행하세요.

**"앱이 닫히지 않았어요"라고 나와요.**
업데이트하려면 켜져 있는 앱을 먼저 닫아야 합니다. 앱을 직접 종료한 뒤 명령어를 다시 실행하세요.

**Intel Mac이나 Linux에서 쓸 수 있나요?**
설치 파일은 제공되지 않습니다. JDK 17 이상을 설치한 뒤 소스로 실행할 수 있습니다
([README의 소스로 실행하기](https://github.com/kim0040/proto#개발자용-소스로-실행하기)).

**인터넷이 없어도 되나요?**
설치할 때만 인터넷이 필요합니다. 앱은 인터넷 없이 동작하고, 일정은 내 컴퓨터에만 저장됩니다.

**한 줄 설치가 안전한가요?**
붙여 넣는 한 줄은 이 저장소의 [Windows 스크립트](../scripts/install-windows.ps1)나
[Mac 스크립트](../scripts/install-mac.sh)를 받아 실행합니다. 열어 보면 앱을 받아 내 사용자 폴더(Mac은 응용 프로그램 폴더)에 넣는 일만 합니다.
