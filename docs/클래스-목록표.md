# 클래스 목록표

소스의 각 클래스 머리 주석(분류와 역할)과 서로 참조하는 클래스를 모아 만든 표다. `협력 클래스`는 그 클래스 코드가 직접 이름을 쓰는 우리 클래스들이다 (많으면 앞 6개만).

전체 133개 클래스 (수업용 121개 + 서버 대비 12개).

## `proto.app`

| 클래스 | 분류 | 역할 한 줄 | 주로 협력하는 클래스 |
|---|---|---|---|
| AppPaths | 애플리케이션 시작점 | 데이터 폴더의 위치를 정한다 | - |
| Main | 애플리케이션 시작점 | 저장소·controller·타이머를 만들어 연결하고 화면(UiLauncher)을 띄운다 | AppPaths, CategoryController, ReminderTimer, ScheduleController, StateRefreshTimer, UiLauncher |
| StoreFactory | 애플리케이션 시작점 | 일정·카테고리 저장소를 만든다 | CategoryRepository, CategoryStore, RemoteApiClient, ScheduleRepository, ScheduleStore, ServerSettings 외 3개 |
