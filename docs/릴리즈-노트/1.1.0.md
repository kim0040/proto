# 일정 관리 1.1.0

시간표에서 일정을 끌어 옮기고, 되돌리고, 색을 칠하고, `⌘K`로 어디든 바로 가는 쪽으로 쓰기 편해진 버전입니다. 1.0.0의 일정 데이터는 그대로 읽습니다.

## 새 기능 (F16~F21)

| 번호 | 기능 | 한 줄 설명 |
| --- | --- | --- |
| F16 | 일정 옮기기 | 이번 주 시간표에서 일정을 끌어 날짜·시간을 바꾸고(15분 단위), 아래쪽 가장자리를 끌어 길이를 바꿉니다. 끌다가 가장자리에 가면 저절로 스크롤되고, `Esc`로 취소합니다. 달력에서는 다른 날 칸으로, 하루 종일 줄에서는 가로로 끌어 옮깁니다. 키보드는 `Alt`(Mac은 `⌥`) + `←` `→`(하루), `↑` `↓`(15분)이고, 우클릭 메뉴에 "내일로 미루기"·"다음 주로 미루기"가 있습니다. 빈 곳을 끌거나 두 번 누르면 그 시간으로 채운 새 일정 창이 열립니다. |
| F17 | 되돌리기·다시 실행 | 일정 변경(만들기·고치기·지우기·완료·옮기기·색 바꾸기) 직후 안내 메시지의 "되돌리기"를 누르거나 `Ctrl/⌘+Z`로 취소합니다. `Ctrl/⌘+Shift+Z`(Windows는 `Ctrl+Y`도)로 다시 실행합니다. 최근 30번까지이고 앱을 끄면 기록은 사라집니다. |
| F18 | 일정 복제·복사/붙여넣기 | 우클릭 메뉴의 "복제"로 같은 날 같은 시간에 사본을 만들고, `Ctrl/⌘+C`·`Ctrl/⌘+V`로 지금 보는 화면의 날짜에 붙여 넣습니다. |
| F19 | 하루 종일 일정 | 일정 창의 "하루 종일"을 켜면 날짜만 정합니다. 오늘 화면 위 띠와 이번 주 시간표 위 "하루 종일" 줄에 나옵니다. 겹침 경고·빈 시간·알림에서는 빠집니다. |
| F20 | 색 지정 | 카테고리 색(12색 팔레트), 일정 하나만의 색(일정 창의 "색" 줄, 우클릭 "색 바꾸기"), 앱 강조색(설정에서 7가지)을 고릅니다. |
| F21 | 명령 메뉴·빠른 이동 | `Ctrl/⌘+K` 명령 메뉴에서 보기·카테고리·테마·설정으로 이동하고, `내일`, `다음 주 금요일`, `11월 20일`처럼 날짜를 쳐서 그날로 갑니다. 한 글자 단축키(`C` 새 일정, `T` 오늘, `D`/`W`/`M` 보기, `←` `→` 이전·다음)와 `?` 단축키 안내가 있습니다. 왼쪽 메뉴에는 일정이 있는 날을 점으로 보여 주는 작은 달력이 생겼습니다. |

## 바뀐 점

- **노션 같은 화면**: 군더더기를 줄이고 글자와 여백을 다듬었습니다. 새 일정·설정·빈 시간 찾기는 별도 창이 아니라 앱 창 안에 겹쳐 뜨는 시트이고, 바깥을 누르거나 `Esc`로 닫습니다. 화면 전환과 끌기에는 부드러운 움직임이 들어갔고, 설정에서 끌 수 있습니다.
- **색**: 카테고리마다 12색 중에서 고르고, 일정마다 따로 칠하고, 앱 전체의 강조색도 바꿀 수 있습니다.
- **일정 삭제**: 반복 일정이 아니면 확인을 묻지 않고 바로 지웁니다. 대신 "되돌리기"로 되살릴 수 있습니다.
- **앱 아이콘**: 흑백의 단순한 모양으로 바뀌었습니다.
- **설치**: 아래 한 줄로 경고 창 없이 설치하고 바로 엽니다. 같은 한 줄을 다시 실행하면 최신 버전으로 업데이트됩니다. 자세한 방법은 [설치 안내](https://github.com/kim0040/proto/blob/main/docs/설치-안내.md)에 있습니다.
  - Windows (PowerShell): `irm https://raw.githubusercontent.com/kim0040/proto/main/scripts/install-windows.ps1 | iex`
  - Mac (터미널): `curl -fsSL https://raw.githubusercontent.com/kim0040/proto/main/scripts/install-mac.sh | bash`
- **내려받는 파일 이름**: 이름에서 버전을 뺐습니다(`ScheduleApp-windows-x64.msi`, `ScheduleApp-windows-x64.zip`, `ScheduleApp-macos-arm64.dmg`, `ScheduleApp-macos-arm64.zip`). 그래서 `releases/latest/download/<이름>` 주소가 늘 최신 버전을 가리킵니다.

## 데이터

- `schedules.csv`가 12칸에서 **14칸**이 되었습니다. 끝에 `all_day`(하루 종일 여부)와 `color`(일정 색)가 붙습니다.
- `categories.csv`에는 `color` 열이 붙어 `id,name,color`가 됩니다.
- 1.0.0에서 만든 파일은 **그대로 읽습니다.** 하루 종일이 아닌 일정, 카테고리 기본 색으로 읽히고, 다음 저장 때 새 모양으로 바뀝니다. 업데이트 전에 따로 할 일은 없습니다.
- 1.1.0에서 저장한 파일을 1.0.0으로 되돌려 열 수는 없습니다(칸 수가 달라 1.0.0은 그 줄을 읽지 못하고 건너뜁니다). 1.0.0으로 돌아갈 계획이면 `schedules.csv`와 `categories.csv`를 미리 복사해 두세요.

## 알려진 한계

- **서명이 없는 앱입니다.** 위의 한 줄 설치를 쓰면 경고 창이 뜨지 않습니다. 파일을 직접 받았다면 처음 한 번 열 때 [설치 안내](https://github.com/kim0040/proto/blob/main/docs/설치-안내.md)의 경고 창 넘기기 방법을 따라 주세요.
- macOS는 Apple Silicon(M1 이후) 전용입니다. Intel Mac용은 없습니다.
- Windows 앱은 x64용입니다.
- 한 사람이 한 컴퓨터에서 쓰는 앱입니다. 여러 기기 동기화는 지원하지 않습니다.
- 알림은 앱이 켜져 있을 때만 뜹니다. 앱이 꺼져 있으면 알려 주지 못합니다.
- 되돌리기 기록은 앱을 끄면 사라지고, 카테고리 변경은 되돌리기 대상이 아닙니다.
- 앱을 지워도 데이터 폴더는 남습니다.
