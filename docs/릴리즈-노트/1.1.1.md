# 일정 관리 1.1.1

왼쪽 메뉴(사이드바)를 다듬은 작은 업데이트입니다. 일정 데이터와 저장 형식은 1.1.0과 같습니다.

## 바뀐 점

- **사이드바 숨기기**: 앱 이름 옆의 버튼(좁은 창에서는 아이콘 줄 아래쪽 버튼), `Ctrl/⌘ + \`, 또는 명령 메뉴(`Ctrl/⌘ + K`)의 "사이드바 숨기기"로 왼쪽 메뉴를 접어 화면을 넓게 씁니다. 숨기면 제목 왼쪽에 다시 보이기 버튼이 생기고, 숨긴 상태는 다음에 앱을 열 때도 그대로입니다.
- **더 빠른 클릭**: 사이드바 항목은 누르는 순간 바로 바뀝니다. 작은 달력, 켜기/끄기 스위치, 색 고르기, 완료 체크 같은 버튼도 누르는 동안 마우스가 조금 움직여도 한 번에 반응합니다. 전에는 트랙패드로 톡 치거나 빠르게 누르면 반응하지 않아 두 번 눌러야 할 때가 있었습니다.
- **좁은 창의 아이콘 줄 정렬**: 메뉴·새 일정·보기·설정 아이콘이 한 줄 가운데에 반듯하게 섭니다.
- **좁은 창에서 메뉴를 펼친 채 창 크기를 바꿀 때** 펼친 메뉴의 내용이 사라지던 문제를 고쳤습니다.
- **코드 정리**: 설명 주석을 다듬고 코드 순서를 맞춰 읽기 쉽게 했습니다. 앱이 하는 일은 같습니다.

## 설치·업데이트

이미 한 줄 설치로 설치했다면 같은 한 줄을 다시 실행하면 됩니다. 자세한 방법은 [설치 안내](https://github.com/kim0040/proto/blob/main/docs/설치-안내.md)에 있습니다.

- Windows (PowerShell): `irm https://raw.githubusercontent.com/kim0040/proto/main/scripts/install-windows.ps1 | iex`
- Mac (터미널): `curl -fsSL https://raw.githubusercontent.com/kim0040/proto/main/scripts/install-mac.sh | bash`
