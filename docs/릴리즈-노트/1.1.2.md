# 일정 관리 1.1.2

버튼 테두리가 깜박이던 문제를 고친 작은 업데이트입니다. 일정 데이터와 저장 형식은 1.1.1과 같습니다.

## 바뀐 점

- **버튼 테두리 깜박임**: 앱을 열면 왼쪽 위 "사이드바 숨기기" 버튼에 파란 테두리가 생겼다가, 다른 창을 보고 돌아올 때마다 보였다 안 보였다 하던 문제를 고쳤습니다. 이제 앱을 열면 아무 버튼에도 테두리가 없습니다.
- **작은 아이콘 버튼**(사이드바 숨기기, 검색, 이전·다음 등)은 마우스로 눌러도 테두리가 남지 않습니다. `Tab` 키로 옮겨 다닐 때는 지금 어디에 있는지 테두리로 보여 줍니다.

## 설치·업데이트

이미 한 줄 설치로 설치했다면 같은 한 줄을 다시 실행하면 됩니다. 자세한 방법은 [설치 안내](https://github.com/kim0040/proto/blob/main/docs/설치-안내.md)에 있습니다.

- Windows (PowerShell): `irm https://raw.githubusercontent.com/kim0040/proto/main/scripts/install-windows.ps1 | iex`
- Mac (터미널): `curl -fsSL https://raw.githubusercontent.com/kim0040/proto/main/scripts/install-mac.sh | bash`
