# 일정 관리 1.0.0

처음 내보내는 버전입니다. Windows와 macOS(Apple Silicon)에서 자바를 따로 깔지 않고 쓸 수 있습니다.

## 기능 (F1~F15)

| 번호 | 기능 | 한 줄 설명 |
| --- | --- | --- |
| F1 | 일정 등록 | 제목, 날짜, 시간, 카테고리, 메모를 넣어 일정을 만듭니다. |
| F2 | 일정 조회 | 오늘, 이번 주, 달력 보기로 일정을 봅니다. |
| F3 | 일정 수정 | 만든 일정을 고칩니다. 반복 일정은 "이 일정만" 또는 "앞으로 전부"를 고를 수 있습니다. |
| F4 | 일정 삭제 | 일정을 지웁니다. 지우기 전에 한 번 확인하며, 지운 일정은 되돌릴 수 없습니다. |
| F5 | 완료 처리 | 끝낸 일정을 완료로 표시하고, 다시 되돌릴 수도 있습니다. |
| F6 | 상태 자동 계산 | 예정, 진행 중, 지연, 완료를 시간에 맞춰 알아서 바꿉니다. |
| F7 | 카테고리 관리 | 카테고리를 만들고, 이름을 바꾸고, 지웁니다. |
| F8 | 검색 | 제목과 메모에서 글자를 찾습니다. |
| F9 | 반복 일정 | 매일, 매주, 매월 반복되는 일정을 만듭니다. |
| F10 | 알림 | 일정 시작 5분·10분·30분 전에 알림 카드를 띄웁니다. 소리는 끌 수 있습니다. |
| F11 | 자동 저장 | 바꿀 때마다 알아서 저장합니다. 저장에 실패하면 알려 줍니다. |
| F12 | 빈 시간 찾기 | 정한 활동 시간대 안에서 비어 있는 시간을 찾아 줍니다. |
| F13 | 일정 겹침 경고 | 다른 일정과 시간이 겹치면 미리 알려 줍니다. |
| F14 | 주간 통계 | 한 주의 일정 수, 완료율, 지연 수, 카테고리별 시간, 요일별 일정 수를 보여 줍니다. |
| F15 | 알림 다시 알리기 | 알림 카드에서 "5분 뒤 다시"를 누르면 5분 뒤에 또 알려 줍니다. |

## 설정 (Ctrl/⌘ + ,)

- 테마: 시스템, 라이트, 다크
- 애니메이션 켜기/끄기
- 시작 화면: 오늘, 이번 주, 달력
- 알림 소리 켜기/끄기
- 빈 시간 찾기의 기본 활동 시간대
- 데이터 폴더 보기와 열기
- 앱 이름과 버전 보기

## 화면 크기에 맞춰 바뀌는 배치

- 창이 넓으면 사이드바가 펼쳐져 있습니다.
- 창이 좁아지면 사이드바가 아이콘 띠로 줄고, 더 좁으면 필요할 때만 나오는 서랍이 됩니다.
- 달력의 날짜 패널과 주간 보기도 창 크기에 따라 자리를 바꿉니다.
- 창 위치와 크기는 기억했다가 다음에 그대로 엽니다.

## 데이터

- 일정은 이 컴퓨터의 CSV 파일에 저장됩니다. 서버나 계정은 필요 없습니다.
- macOS: `~/Library/Application Support/ScheduleApp`
- Windows: `%APPDATA%\ScheduleApp`
- 앱을 두 번 켜면 두 번째 창은 "이미 실행 중이에요"라고 알리고 끝납니다.

## 알려진 한계

- **서명이 없는 앱입니다.** macOS는 "우클릭 → 열기", Windows는 SmartScreen의 "추가 정보 → 실행"으로 처음 한 번 열어 주세요. 자세한 방법은 [배포하는 법](../배포-하는-법.md)에 있습니다.
- macOS는 Apple Silicon(M1 이후) 전용입니다. Intel Mac용은 없습니다.
- Windows 앱은 x64용입니다.
- 한 사람이 한 컴퓨터에서 쓰는 앱입니다. 여러 기기 동기화는 지원하지 않습니다.
- 알림은 앱이 켜져 있을 때만 뜹니다. 앱이 꺼져 있으면 알려 주지 못합니다.
- 앱을 지워도 데이터 폴더는 남습니다.
